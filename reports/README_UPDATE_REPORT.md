# README UPDATE REPORT

## Какие секции добавлены

- **Features** — список возможностей: сегментация, автоворонки, серия сообщений по расписанию, сбор заявок, админ-панель, редактирование сценариев, рассылка, статистика, rate limiting, healthcheck.
- **Use cases** — для кого бот: онлайн-курсы, инфобизнес, маркетинговые воронки, услуги и агентства, продажи через Telegram.
- **Architecture** — структура проекта (config, models, services, handlers, middlewares, scheduler, alembic) и стек технологий (Python 3.11, Aiogram 3, PostgreSQL, SQLAlchemy 2, APScheduler, Docker).
- **Installation** — локальный запуск, Docker, миграции.
- **Deploy** — команды для деплоя на сервер (clone, .env, docker compose prod).
- **Screenshots** — секция с указанием, что скриншоты можно добавить позже, и папки `docs/screenshots/`.

README приведён к формату портфолио-проекта: краткое описание, demo-бот, блоки Features / Use cases / Architecture / Installation / Deploy / Screenshots и переменные окружения.
